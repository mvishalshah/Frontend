# Kya Scene Hai

Campus Event Discovery Website, built for the TechSpace Frontend recruitment task (USIC&T, GGSIPU).

Search and category filters, event detail modal with registration form validation, bookmarks saved in localStorage, dark and light mode, loading and empty states, responsive on mobile and desktop.

**Stack:** React 18, Vite, plain CSS. Event data lives in `src/data/events.json`.

## Run locally
```
npm install
npm run dev
```

## Deploy on GitHub Pages
1. Push this folder to a new GitHub repo on the `main` branch.
2. In the repo go to Settings, then Pages, and set Source to **GitHub Actions**.
3. Every push to `main` builds and deploys. The link appears in the Actions tab.
